# 2026-09-12 本地优化与验证

本轮保留当前网页和离线报告的视觉设计，只扩展证据导出入口并修复执行边界。未发布 GitHub，未录制视频。

## 修复

1. **GBK 环境下的 Unicode 输出异常**：未设置 `PYTHONUTF8=1` 的基线运行中，修复版 DataCraft 在第 65 个用例输出 emoji 时触发 `UnicodeEncodeError`，并可稳定重放。两个教学版本现在明确输出 UTF-8 字节。增加强制 GBK 标准流环境的回归用例，没有改写通用执行器对其他待测软件的环境。
2. **种子执行期间停止被当作基线失败**：取消结果独立于种子校验错误处理。用户停止和总预算耗尽分别记录 `completion_reason`，原始结果仍保留。
3. **完成后立即启动下一任务偶发被拒绝**：任务启动时允许已完成的工作进程在 1 秒内完成退出，仍然保证单任务执行。最终摘要先写入磁盘，再发布终态，避免下载时看到缺少最终摘要的结果。
4. **重放来源对象被修改**：任务创建复制传入的来源字典后再取出输入数据，调用者可以继续使用原始来源对象。

## 完整证据 ZIP

任务结束后，详情页面提供“完整证据 ZIP”。包含离线 HTML、JSON 报告、任务快照、正常种子、逐用例日志、失败输入、缩减输入、重复失败记录、可用的基线错误证据及 SHA-256 清单。

只包含白名单范围内的任务证据，排除 scratch、工作进程日志和目标程序；拒绝越出任务目录的证据路径。文件按块写入 ZIP，归档大于 8 MiB 时转入临时文件，响应结束关闭资源。运行中返回 HTTP 409，避免打包不完整快照。原始证据打包上限 256 MiB / 20000 文件。
