# DataCraft 教学目标

两个目录包含相互独立的命令行程序。平台不会 import 它们，也不会根据文件名或字段名生成特殊输入。

正常种子：

- `01-ratio.json`：12 / 3，输出 4.0。
- `02-repeat.json`：重复 3 次 hello。

程序约定：成功返回 0；正常拒绝非法输入返回 2。

JSON 输出明确使用 UTF-8 字节，不依赖 Windows 控制台或 Python 标准流的默认编码；中文与 emoji 输入在 GBK 环境下也可正常处理。

`datacraft-buggy` 人工保留三类教学缺陷：

1. 未校验字段存在就访问，触发 KeyError。
2. 未校验除数及操作数类型，触发 ZeroDivisionError / TypeError。
3. 重复次数为负数时循环无法终止，平台观察为超时。

平台按异常类型与调用位置归组，同一缺陷可能对应多个失败签名。

`datacraft-fixed` 校验字段、类型和数值范围，对非法输入正常拒绝。可以用原始/缩减输入回归，并对正常样例重新测试。

这两个程序用于演示从发现问题到验证修复的完整流程。
